# Grouped multi-date activity UI update

- Admin multi-session editor now groups sessions beneath each selected date.
- Administrators can add a date, then add multiple time slots and capacities under that date.
- Public registration now follows a date-first, time-slot-second flow.
- Homepage event cards show one capacity-status indicator for each activity date.
- Existing database schema and multi-session RPCs are reused; no new migration is required.
