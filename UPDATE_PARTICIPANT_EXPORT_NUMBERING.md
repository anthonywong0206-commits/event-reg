# Participant list Excel numbering update

- Registration numbers now restart from 1 for every date/time session group.
- Multi-date activities therefore restart numbering independently for each day's session(s).
- Multi-session activities restart numbering independently for each individual time slot.
- Multi-session worksheets now show the total number of confirmed participants for that worksheet date near the top.
- Participant order inside each group remains based on registration creation time (earliest first).
- Existing export columns and the exclusion of waitlist/cancelled registrations are unchanged.
